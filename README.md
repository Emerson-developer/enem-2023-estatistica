# Desempenho no ENEM 2023 — População, Amostra e Inferência

Trabalho de Probabilidade e Estatística para IA (Emerson Lima).

- Painel 1 · População: `index.html#populacao`
- Painel 2 · Amostra: `index.html#amostra`
- Painel 3 · Inferência: `index.html#inferencia`

Fonte dos dados: [Microdados do ENEM 2023 — INEP/MEC](https://www.gov.br/inep/pt-br/acesso-a-informacao/dados-abertos/microdados/enem).
`analise_enem.py` reproduz a análise (amostra aleatória simples com semente 2026); `amostra_aas_enem.csv` é a amostra sorteada.
